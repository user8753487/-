Проект: Веб-приложение «Копеечка Доставка» NEW

Описание: Новый сервис для заказа продуктов онлайн с быстрой доставкой на дом. Проект включает в себя личный кабинет пользователя и панель администратора для сборки заказов.

Статус: В разработке.

Янусов Даниил (Frontend-разработчик)

Проекты, которые он сделал:

  • Сайт магазина «Копеечка» — верстка главной страницы и каталога товаров.
  • Дизайн-система — создание библиотеки UI-компонентов для внутренних проектов.
  • Промо-лендинг «Скидки к выходным» — одностраничный сайт для рекламной акции.

Лемешев Даниил (Backend-разработчик)

Проекты, которые он сделал:

  • База данных склада — проектирование и настройка SQL-базы для учета товаров.
  • API для мобильного приложения — серверная часть для обмена данными с приложением скидок.
  • Telegram-бот «Копеечка-Бот» — бот для уведомлений сотрудников о новых поставках.

  • Виджет для iOS — виджет с актуальными акциями на главный экран iPhone.

Сафроненко Егор (Тестировщик / QA)

  • Система мониторинга ошибок — настройка сервиса, который собирает баги от пользователей.
  • Нагрузочное тестирование API — проверка сервера на устойчивость при большом количестве посетителей.
